# Política de segurança

## Versões com suporte

O ArtWeb OS está em desenvolvimento inicial. No momento, somente a versão mais recente publicada recebe correções de segurança.

## Como relatar uma vulnerabilidade

Não abra uma issue pública contendo chaves, senhas, dados pessoais ou detalhes que permitam explorar uma falha.

Use o recurso **Private vulnerability reporting** do GitHub, quando disponível no repositório, e inclua:

- descrição do problema;
- passos para reproduzir;
- impacto observado;
- versão ou commit afetado;
- sugestão de correção, se houver.

Evite acessar, alterar ou baixar dados de outras pessoas durante a investigação. O recebimento do relato será confirmado assim que possível e as atualizações serão publicadas na área de releases.
